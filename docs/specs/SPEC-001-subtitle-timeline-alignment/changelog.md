# Changelog: SPEC-001 SubAlign 字幕时间轴音频对齐

## [2026-11-05] - 模型选择与鲁棒分段

- **修改类型**: Changed
- **影响范围**: 4.5 rules 3–5、4.6 `ERR_AMBIGUOUS_FIT`
- **变更原因**: Patagonia 真实数据中，零时长 token 修复后仍出现线性模型被斜率显著性门槛误拒、动态规划分段不稳定又误阻断写回
- **具体内容**: 线性模型按 RMSE 改进选择，斜率只作诊断；分段改为局部中位数 + 变点，最少 3 个锚点；分段未优于线性时保留线性/常量，不因断点抖动阻断

## [2026-11-05] - 新增 --shift 人工校准

- **修改类型**: Added
- **影响范围**: 4.2 CLI 参数、4.5 rule 7
- **变更原因**: 真实《印象派》输出目测整体快约 0.6s，需要一个显式的整体校准参数，而不是改代码或重新拟合
- **具体内容**: 新增 `--shift <秒>`，默认 0；模型拟合后加到截距（piecewise 加到每个分段偏移）；正数表示字幕更晚

## [2026-11-05] - 修正时间写回与重叠处理

- **修改类型**: Changed
- **影响范围**: 4.5 rule 7
- **变更原因**: 真实《印象派》ASS 存在大量同时刻排版事件；全局重叠推移会级联把旁白推到 30s，高置信行直接使用原始锚点也会把离群值写进字幕
- **具体内容**: 所有行统一使用拟合模型预测；锚点只参与拟合与置信度；保留原时长与间隔，不做全局重叠推移；负起点夹紧并写 `WARN_CLAMPED`

## [2026-11-05] - 默认模型改为 large-v3-turbo

- **修改类型**: Changed
- **影响范围**: 2.1 G5、4.2 `--model`、5.1、5.5、CLI/pipeline/ASR 默认值
- **变更原因**: 首版验证与当前机器使用 `large-v3-turbo`；`large-v3` 需要额外下载，作为默认会让首次运行直接失败
- **具体内容**: 默认模型统一为 `large-v3-turbo`；`large-v3` 仍可通过 `--model large-v3` 显式指定，DTW 名称映射保持不变

## [2026-11-05] - 状态流转：Draft → Approved

- **修改类型**: Changed
- **影响范围**: frontmatter status、tasks.md status
- **变更原因**: 主笔批准开始实施
- **具体内容**: Spec 与执行拆解状态置为 `Approved`；按 `tasks.md` 的依赖顺序开始实现

## [2026-11-05] - 修正首版回滚路径

- **修改类型**: Changed
- **影响范围**: 6.4
- **变更原因**: 独立评审指出首版 `v0.1.0` 没有「上一个 tag」，回滚步骤不能回退到自身
- **具体内容**: 回滚步骤区分「已有上一版本」与「首版」两种情况；首版回退到发布前提交或直接卸载

## [2026-11-05] - 修正编码策略与 ASS 保真冲突

- **修改类型**: Changed
- **影响范围**: 3.2, 4.1, 5.5, 6.2
- **变更原因**: 独立评审发现「ASS 非时间字段逐字节一致」与「输出统一 UTF-8/LF」在 GB18030 或 CRLF 输入下不可能同时成立
- **具体内容**: 输出沿用输入的编码、BOM 与换行风格，不做转码；字幕层职责从「统一编码」改为「编码探测 + 原样写回」

## [2026-11-05] - 固定识别输入音频格式

- **修改类型**: Changed
- **影响范围**: 3.2–3.3, 4.1, 4.4, 4.6, 5.5, 6.3, architecture/system.md, tasks.md
- **变更原因**: 实际踩过的坑：识别前没有把音频统一成固定编码，whisper.cpp 的输入不可控
- **具体内容**: 媒体层固定输出 16kHz / 单声道 / PCM `s16le` WAV，ffmpeg 参数固定为 `-ar 16000 -ac 1 -c:a pcm_s16le`；ffprobe 校验四项格式，新增 `ERR_MEDIA_FORMAT`；冒烟覆盖 44.1kHz 立体声输入的归一化

## [2026-11-05] - 支持 ASS 与中英双语

- **修改类型**: Changed
- **影响范围**: 1.4, 2.1–2.2, 3.1–3.4, 4.1–4.6, 5.5, 6.2–6.4, 7.6–7.8, 附录 A, tasks.md
- **变更原因**: 实际使用的字幕是 ASS 格式，且同一文件里同时有中文和英文；原方案只覆盖 SRT 单语，无法落地
- **具体内容**: 字幕层扩展为 SRT/ASS 双格式，ASS 仅重写 `Dialogue` 的 `Start`/`End`；新增语言标注与双语分组，按 ASR 语言选择锚点行、译文行跟随同一修正量；数据模型与报告增加 `format`、`group_id`、`anchor_lang`；新增 T11 与 8 个 SRT/ASS 双语 fixture

## [2026-11-05] - 技术选型修正：WhisperX → whisper.cpp

- **修改类型**: Changed
- **影响范围**: 1.3, 3.1–3.4, 4.3–4.4, 5.4–5.5, 7.5–7.7, 附录 A
- **变更原因**: 实际使用的本地识别工具是 whisper.cpp，不是 WhisperX；两者在时间戳生成方式与边界精度上不同，必须写进选型理由与精度风险
- **具体内容**: 识别层改为 whisper.cpp（GGML 模型、DTW token 时间戳）；`WordToken` 改为 `AsrToken` 并明确 token 重组规则；7.5 增加 WhisperX 对照与精度兜底；附录 A 增加「token 时间戳是否足以支撑 G1」的未决项
